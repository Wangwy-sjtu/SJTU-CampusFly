## 1.0.3 上传兼容性修复（2026-09-19）

对照用户提供的原版 SJTURunningMan-Stable，确认原版在规则缺少 id 时先默认 6 再映射为 9；重构版此前直接使用 6。本次只读 GET 查询确认当前学校 rules 对象未带 id，因此恢复缺省编号 9，服务器显式编号仍保留。

原版从当前时间生成轨迹后等待跑步时长，重构默认 WAIT_BEFORE_UPLOAD=False 导致未来时间点直接提交。现真实模式始终等待至最后轨迹时间到达；已经结束的历史轨迹无需等待。等待支持取消，并显示尚未提交。

恢复原版鉴权与上传 User-Agent / Host 等关键请求头。规则响应非成功或无有效规则时中止；code=0 不再宣称学校成绩已确认，不自动重试。模拟结果及按钮明确标记未上传。

55 项 Python 测试和地图 JS 回归检查通过。测试包括无 id 的真实规则形态、错误规则阻断、原版上传请求头、未来轨迹等待、取消不提交、历史轨迹不等待、模拟不访问网络、空 data 不重试。

仅执行授权信息、历史汇总和规则 GET 查询；未提交真实跑步记录。学校实际入账结果仍待用户验证。
