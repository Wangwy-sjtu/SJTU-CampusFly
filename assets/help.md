# SJTU校园飞 帮助

## 先确认地图状态

窗口左侧会明确显示“腾讯地图”或“离线坐标网格”。离线网格只是坐标工作区，不包含真实道路；没有腾讯 Key 时不要把网格线当作校内道路。离线状态可以使用“自由手绘（兼容）”，道路吸附和路网规划需要腾讯底图。

如果要加载腾讯底图，请在右侧填写腾讯地图 JavaScript API V2 Key，点击“应用地图凭据”，然后观察地图状态。Key 只保存在本机被忽略的私有配置中。腾讯底图显示成功只证明 SDK 和地图组件加载，不等于闵行校内道路覆盖或学校接口坐标系已经验证。腾讯地图的 `qq.maps.LatLng` 和鼠标画点使用同一套腾讯工作坐标，路线记录为 `gcj02`；旧的 WGS84 路线不会自动转换，清空后再绘制才能写入腾讯坐标。

初始视野按剑川路、东川路、沧源路、莲花南路围合的闵行工作范围适配。视野范围不是路网数据，程序不会因为道路出现在范围内就自动吸附。当前运行时路网是 `data/tencent_road_graph.candidate.json` 的腾讯步行采样候选图，由真实步骤 polyline 去重形成，元数据标记为局部候选；旧 `data/minhang_road_graph.json` 和 `data/visual_trace/` 只作为核验/回滚证据保存，未标注道路不会被吸附或自动连通。

在已经建立一笔连续 GCJ-02 路线后，可以点击“查询并标记腾讯步行道路”。程序在后台以该笔的起终点调用腾讯 WebService 步行接口，地图上的黄色线表示接口返回的真实 polyline，状态和日志会列出返回的道路名。该接口只规划两点之间的路线，不能提供完整校园路网；确认现场底图对齐后，再点“采用首选腾讯路线”写入当前路线快照。腾讯 Key 不会写入路线文件或日志。

## 绘制路线

“道路吸附画笔”是默认模式。按住鼠标拖动到屏幕像素阈值内的真实节点，候选节点会实时高亮，并预览从当前节点到候选节点的腾讯候选图显式连接；超出阈值或不可达时，程序保持已有路线，不会跳接到另一条道路。候选使用滞回避免在邻近节点之间抖动，绘制时地图平移会锁定；每次成功连接作为一段保存，点击“撤销上一笔”会撤销整段连接，之后可从末端继续。

“自由手绘（兼容）”不吸附道路；旧的点击选路路线载入后会迁移到道路吸附画笔，并保留原有路线几何。

节点吸附画笔选中的首个节点或当前路线保存的起点可用于目标公里数开放路线规划；没有可核验起点时，界面会明确提示先选节点或载入已有路线。程序显示目标距离、实际距离和误差，终点由当前路网决定，不默认返回起点。圈数只接受闭合基础路线，开口路线会拒绝，不会静默补回起点。

“撤销上一笔”只撤销最后一笔，“清空路线”清除当前路线。“保存路线”和“载入路线”只读写路线 JSON，不需要登录信息。

## 预览和上传

路线距离是每一笔内部边长的总和。预计时长使用速度和同一条路线快照计算。生成轨迹时会保留拐点、闭环和交叉顺序，不插入服务器打卡点。最终预览和 mock 上传读取同一份路线快照。

默认上传模式是离线模拟，不会访问交大服务器。模拟完成只显示“本地模拟完成，未上传到学校”；它不会计入联网统计。真实接口模式的成功码会显示“已提交，待核实”，不会宣称记录已确认，也不会自动重复发送。

多笔路线若笔画末尾与下一笔起点相距超过约 25 米，仍可预览和保存，但上传校验会拒绝，避免把空间跳跃静默当作连续跑步轨迹。

程序会在日志中隐藏 Cookie、JSESSIONID、keepalive 和 Authorization token。服务器坐标系未知时，界面会明确标注，程序不会假装已经完成坐标转换验证。

## 帮助 / 关于与联网统计

创作者：**殇霞与夕夏**。

应用会在后台每 60 秒，或产生真实提交事件后，联系 `https://998223.xyz/campusfly/api/v1/sync`，同步随机生成的安装编号、应用版本和三类粗粒度事件：安装、真实提交尝试、学校接口返回成功码。本地模拟、登录失败、生成失败、取消等待和没有发出学校 POST 的操作不会计入提交统计。成功码只表示学校接口接受了请求，不表示学校记录已经入账。

安装编号是保存在本机的随机 UUID，帮助管理员识别一台安装；它不是硬件指纹。统计服务不会收到 IP、硬件标识、学校账号、Cookie、腾讯 Key、路线或轨迹内容。安装编号和事件队列保存在用户数据目录的 `configs/management.local.json`，事件会去重、限量保存并在收到确认后删除。

管理服务可以按安装编号或全局要求暂停服务。收到明确停用状态后，窗口显示“应用已停用”，编辑器和未提交任务会停止，但本地路线、配置和本页帮助仍保留；后台继续轮询，以便收到恢复状态。网络失败保留上一次有效状态，不会因为离线或超时自动停用。已经发出的 HTTP 请求无法撤回，学校接口的最终记录状态仍需另行核实。

“应用已停用”页面会显示本机安装编号和本地事件计数，便于将编号提供给管理员。统计连接是后台的短请求，不会弹出同意窗口；上述行为和数据范围在此公开说明。

管理员发布的公告会在应用启动后的第一次有效同步中以可关闭的纯文本窗口显示。相同公告编号在本机确认显示后不会在后续轮询中重复弹出；新的公告会在下次启动时显示。公告内容只作为纯文本展示，不会执行 HTML、脚本或自动打开链接。
